# Agreed decisions and factual guardrails

- Buyer-first homepage with two subordinate public routes: Sellers, Agents.
- Two languages, English and Polish; Polish should sound natural and be skimmable.
- Vesteri Collective = selective professional network; agents need approval before listings go live.
- Seller value proposition: one designated agent + opportunities from the network. Cooperation is a Collective principle; do not state every member will actively market every listing.
- The seller may choose a participating agent or ask Vesteri to help select one. Contractual authority and exclusivity details must be confirmed before production claims.
- Marketing/product copy uses **Vesteri system** (not Estalara), but platform domain is `vesteri.estalara.com`.
- Marketplace can display static photographs selected from real listings. Exact per-listing URLs must be provided or verified; no API integration at this stage.
- EN and PL only for new public marketing pages; retain existing Affiliate Program with all actual functionalities; link in footer.
- Buyer LIVE presentations, webinars, consultations and AI support must not be presented as bookable on Vesteri.com if no matching functional destination exists.
- Current price model statements: free application/listings/core use; pay-as-you-go or subscription for extras. Review against the actual account pricing.
- Cooperation obligations, standard commission division, foreign-developer commissions in 5–8% range, larger share to introducing agent, and 10% revenue marketing pledge must be reconciled with the operative Collective terms before publishing as binding promises.
- Buyer-facing caveat: verified network membership does not establish legal/technical status for every property. Do not remove important safeguards from buyer FAQ just because a short agent-facing copy was simplified.
- Do not reintroduce Community section, fake API integration, automatic commission tracking (not yet launched), or old public marketing pages.
